Loop Engineering hoops: compose fields here, edit stage and swarm graphs on the tab. Pure-local default (Ollama/vLLM). See docs · deep architecture.

How it works
  1. Build stages on Graph editor (palette + Link mode), then Create / Update hoop here.
  2. Click a hoop card to bind the Agent log, then Start -- cycle runs Memory → Router → Planner → Actor → Critic.
  3. Swarm is a one-shot fan-out: link orchestrator to worker roles on the graph, set prompt, Run swarm. Merge summary appears below.
  4. MCP tools: connect servers on the tab, then bind them on a stage (Edit → MCP servers / tools).

Parallel actors inside a hoop also call swarm.FanOut mid-cycle when a stage has parallel > 1. Docs: Tools & MCP.
