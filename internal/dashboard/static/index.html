Tools catalog

Agent CLIs

The other AI coding CLIs on this computer. Push Launch interactively to open a CLI in its own window. To send a task to a CLI, type its name at the END of a message. For example, "fix this bug /claude". The answer comes back to the session that you typed in. /agy is different: it opens a window and returns nothing, because the default template of agy is interactive. Use "/agy:headless" for an answer you can act on.

Default project folder

These CLIs use this folder when Glider cannot find your project. If you leave the field empty, Glider asks you the first time that it needs the folder.

Delegated task replies

This setting controls the reply that you see when Glider sends a task to another CLI. Clean shows only the final answer. Raw shows all the text of that CLI. Use Raw to find the cause of a problem.

    Use the form below as the primary editor. Save writes the config file. Glider then applies the routing rules, the aliases, the context limit, the log level and the backend and model clients (Ollama, vLLM and cloud). You must restart Glider to change the ports, the MITM CA or the MITM hosts. A completion that is in progress keeps the old backend client until it ends. To see this, open the Rules Engine page and look at the backends hot-swap module (last_ok and the generation number). You can also read the X-Glider-Backend-Reload header on a save.
