Core

Architecture

Glider is a shared harness: every completion (gateway or MITM) goes through alias → tokenize → route → transform → execute.

For Path A/B lifecycles, sticky cloud, fulfill hub, and failure modes, see the architecture deep dive, data-flow sequences, module map, and concurrency model.

Pipeline

CompletionRequest

  → transform (local context / Anthropic normalize)
  → executor (Ollama | vLLM | OpenAI | Anthropic)
  → metrics + contextgraph events
