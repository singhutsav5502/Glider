Chain: sticky cloud

Turn-family sticky lives on AgentFulfillHub, not inside router.Engine. Prevents summary/title chrome from stealing a /cloud parent onto Small Context Local. 

OpenTurnFamily(rootUUID, StickyCloud|StickyLocal, source)
        │
        ├── StickyLocal MUST NOT downgrade live StickyCloud
        │     (ParentActive > 0 OR Until in future)
        │
        ├── BeginParentRun / EndParentRun  (root cloud RunSSE)
        │     ParentActive++ / --
        │     End: Until = now + max(familyTTL, DefaultCloudPostRunGrace=120s)
        │
        └── ShouldStickyCloudOrigin(userText, source, …)
              ├── allowlisted fresh TipTap user → may re-decide
              ├── marker chrome user_visible_* → origin
              └── else ArmOrigin (deny-local while StickyCloud live)

Constants: DefaultTurnFamilyTTL=90s · pending offer TTL=30s · Wait=800ms
Graph sync: contextgraph.DefaultCloudGrace / LiveCloudFamily
  1. Open family on explicit or DecideLocal cloud|local OpenTurnFamily · EventTurnOpened · EventStickyBound
  2. Parent RunSSE keeps family alive BeginParentRun / EndParentRun · grace 120s
  3. Follow-on Bidi hits sticky belt before classifier ShouldStickyCloudOrigin · InheritTurnFollowOn · composer_wrapup
  4. Fresh TipTap user may re-decide IsAllowlistedFreshTipTapUser · ≥16 chars · not chrome/child
