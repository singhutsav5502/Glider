Path B — sticky /cloud origin

User types /cloud … TipTap
  → BidiAppend extract sees explicit /cloud
  → ArmOrigin(reqID)
  → OpenTurnFamily(StickyCloud, "explicit_cloud")
  → EventTurnOpened + EventStickyBound

RunSSE root
  → Wait → offer Local=false  OR  timeout → origin
  → BeginParentRun (ParentActive++)
  → tunnel TLS to Cursor origin (subscription)
  → stream cloud tokens to Cursor
  → EndParentRun → Until = now + max(90s, 120s grace)

Later: summary / title chrome (new UUID, user_visible_*)
  → ShouldStickyCloudOrigin / InheritTurnFollowOn
  → ArmOrigin  (must not flip to local small_local classifier)
  → origin passthrough again

A live StickyCloud family refuses downgrade from a late StickyLocal open. Marker chrome stays origin even after TTL expiry. Only IsAllowlistedFreshTipTapUser may re-decide while StickyCloud is live.

Hub Arm/Wait races

OrderMechanism
Bidi first Offer stored in pending[reqID]; RunSSE Wait pops immediately; 30s GC via expirePending
RunSSE first Registers waiting[reqID] buffered chan(1); Bidi signal sends; Wait returns
Timeout race After 800ms, Wait deletes waiter then re-checks pending in case Bidi landed on the wire
No offer Fail-soft origin (runsse_wait_origin) — idle/prewarm reconnects must not hang

Config hot-reload

File change on configs/*.yaml
  → config.Provider.Watch
  → atomic.Pointer swap Config
  → rebuild router.Engine (main atomic.Pointer)
  → hotswap.Registry.Apply hot modules (generation++)
  → MITM routing policy refresh
  ✗ ports / CA / hosts / transparent-interception / backend clients → require restart

Context transform data shape

Path B extract (one turn):
  messages: [ {role:user, content: "<TipTap latest text>" } ]
  tools: none
  → BoundLocalContext ≈ no-op

Path A local:
  full history + tools in body for routing
  → InjectEpisodeContext (compressed)
  → BoundLocalContext(latest_turn) before execute
  → local model never sees full TipTap mega-dump
