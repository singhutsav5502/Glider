Sample hoops

YAML under samples/hoops/. All default to route: local for Ollama smoke tests.

Prerequisites

ollama serve
.\glider.exe --config configs\glider.local.yaml
# Dashboard up on :8081

Run one

go run ./scripts/loadhoop -file samples/hoops/hello-critic.yaml -start
# watch: GET http://127.0.0.1:8081/api/loops
# or Dashboard → Hoops & Swarm

Catalog

FileWhat it doesIterations
hello-critic.yaml Smoke: planner/actor/critic say hello; critic scores completeness 2
explain-snippet.yaml Explain a short Go function in plain language 2
rename-suggest.yaml Suggest clearer names for a poorly named helper 2
review-lite.yaml Light code review of a tiny diff (maker/checker) 3
summarize-notes.yaml Summarize bullet notes into 3 takeaways 2

Install all into ~/.glider/hoops

go run ./scripts/loadhoop -dir samples/hoops
# creates via API + mirrors YAML; add -start -id hello-critic to run one

PowerShell helper

powershell -File scripts\run-sample-hoop.ps1 -Name hello-critic
