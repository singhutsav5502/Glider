User guide: Hoops, Graph, Swarm

  1. Stage graph — build the hoop pipeline (palette, Link mode, Fit). Create / Update on Hoops tab.
  2. Start hoop — click the card to bind Agent log (Following hoop <id>), then Start. Cycle uses stages from the graph.
  3. Swarm wave — link orchestrator to worker roles on Swarm graph; Run swarm calls swarm.FanOut + merge; log follows turn_id.
  4. In-hoop parallel — YAML parallel: 2+ on an actor also uses FanOut mid-cycle (see incident-triage.yaml).

Per-instance agent logs

Each hoop id and each swarm turn_id has an independent ring buffer. Selecting a hoop or finishing a swarm run switches the UI stream (structured rows: time | level | stage/role | message). API:

GET /api/agent-logs?scope=hoop&id=incident-triage
GET /api/agent-logs?scope=swarm&id=swarm-...

WebSocket /ws events with type: agent_log include scope and instance_id.
