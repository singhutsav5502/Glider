Per-instance agent logs

Each swarm turn_id has an independent ring buffer. Selecting/finishing a swarm run switches the UI stream (structured rows: time | level | stage/role | message). Entries carry a monotonic seq; the dashboard polls with after_seq for incremental merge. API:

GET /api/agent-logs?scope=swarm&id=swarm-...

WebSocket /ws events with type: agent_log include scope and instance_id.
