Tools & MCP

Glider unifies builtins and Model Context Protocol (MCP) servers under internal/tools. Hoop stages and swarm workers declare tools: refs; the registry dispatches them (and feeds results into the model when the agentic tool loop is active).

GitHub token (env only)

Never put a PAT in YAML or hoop specs. Set one of these in the Glider process environment (first non-empty wins):

GITHUB_PERSONAL_ACCESS_TOKEN=ghp_...   # preferred
GITHUB_TOKEN=ghp_...
GH_TOKEN=ghp_...

Config validation rejects inline auth.token; use token_env only.

Dashboard MCP UI

  1. Open Dashboard → MCP tab (http://127.0.0.1:8081).
  2. Check GitHub MCP card: token configured? HTTP / stdio connected?
  3. Use Connect / Disconnect / Reconnect / Refresh on each server row.
  4. Click a row (or Tools) to load the tools catalog (live when connected; GitHub falls back to a documented catalog).

Binding tools on stages / nodes

  1. Graph editor → select a stage → Edit.
  2. Check MCP servers and optionally specific tools (empty tool picks = bind all from those servers).
  3. Advanced: Tools JSON for builtins, e.g. {"name":"fs_list","kind":"builtin"}.
  4. Create / Update the hoop on the Hoops tab — tools are persisted on StageSpec.tools.

Also linked from Hoops and Graph help panels. Planning notes: planning/tools_mcp.md.

Seed sample hoops & swarms

powershell -File scripts\seed-samples.ps1
powershell -File scripts\seed-samples.ps1 -Start
.\scripts\seed-samples.ps1 -Base http://127.0.0.1:8081

Loads every top-level YAML under samples/hoops/ and samples/swarms/ (upsert hoops via dashboard API; write swarm templates to ~/.glider/hoops). Requires the dashboard for hoops. Details: Samples · Seed all.
