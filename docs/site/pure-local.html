Ollama

Pure local mode

In this mode Glider does not use a cloud API key. Glider sends all requests to the local model.

Start

ollama serve
ollama pull qwen2.5-coder:14b
.\glider.exe --config configs\glider.local.yaml

The default local model is qwen2.5-coder:14b. The aliases gpt-4o and claude-3.5-sonnet also point to this model.

The settings in glider.local.yaml

  • routing.default: local — makes the local model the default route.
  • routing.allow_cloud_fallback: false — stops each change to a cloud model.
  • mitm.agent_rpc_canned_on_error: false — stops the fixed test reply that can hide a local failure.
  • mitm.origin_on_local_error: false — shows the Ollama error. Glider does not send the request to the origin.
  • mitm.require_local_healthy: true — Glider uses the local model only when that model is serviceable.

Gateway mode (no MITM)

Set mitm.enabled: false. Then set Override Base URL to http://127.0.0.1:8080/v1.
