Ollama

Pure local mode

Run the harness with no cloud API keys and default route local.

Start

ollama serve
ollama pull codellama:7b   # or edit models in yaml
.\glider.exe --config configs\glider.local.yaml

Knobs in glider.local.yaml

  • routing.default: local
  • routing.allow_cloud_fallback: false
  • mitm.agent_rpc_canned_on_error: false
  • mitm.origin_on_local_error: false — clear Ollama errors vs silent Cursor origin
  • mitm.require_local_healthy: true

Gateway-only (no MITM)

Set mitm.enabled: false. Cursor Override Base URL → http://127.0.0.1:8080/v1. Hoops use /api/loops with route: local.

Sample local hoop

go run ./scripts/loadhoop -file samples/hoops/hello-critic.yaml -start
