Ollama

Pure local mode

Run the harness with no cloud API keys and a local default route.

Start

ollama serve
ollama pull qwen2.5-coder:14b
.\glider.exe --config configs\glider.local.yaml

Default local model across configs: qwen2.5-coder:14b (aliases map gpt-4o / claude-3.5-sonnet onto it).

Knobs in glider.local.yaml

  • routing.default: local
  • routing.allow_cloud_fallback: false
  • mitm.agent_rpc_canned_on_error: false
  • mitm.origin_on_local_error: false — clear Ollama errors instead of a silent origin fallback
  • mitm.require_local_healthy: true

Gateway-only (no MITM)

Set mitm.enabled: false. Override Base URL → http://127.0.0.1:8080/v1.
