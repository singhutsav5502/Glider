Memory

Context management

Hybrid dual-layer store: append-only event log (runtime provenance) + entity/edge graph (EXTRACTED | INFERRED | RUNTIME) + in-memory turn index for sticky routing.

Why

Without a memory layer, Composer wrap-ups and subagents look like new small prompts and get mis-routed to local. The graph answers: "is this still part of turn family X?" Dual-layer Query / context_query also answers structural questions (episode / file / symbol) without dumping transcripts.

Dual-layer model

LayerRoleProvenancePersist
Event log Append-only verbs (RouteDecided, FulfilledLocal, OriginPassthrough, FileTreeIndexed, …) Prefer RUNTIME; EXTRACTED when attrs come from tools ~/.glider/context/events-*.jsonl
Entity / edge store file, dir, symbol + relations (contains, references, …) EXTRACTED | INFERRED | RUNTIME ~/.glider/context/entities.jsonl

Query surface

Store.Query / QueryWith / tool context_query search both layers. Filters:

context_query: <turn_id> [key=file-tree] [kind=note|file|dir]
  [prov=RUNTIME|EXTRACTED|INFERRED] [neigh=id] [explain=id] [communities=1] keyword…

Examples:
  t-abc key=file-tree
  t-abc prov=EXTRACTED readme
  t-abc explain=sym:demo.go#Helper
  t-abc communities=1
  prov=RUNTIME RouteDecided

IndexFileTree records a file-tree key. PathSummary(turn, from, to) prefers entity edges, falls back to event scan.

Explain(id) returns neighborhood + hub/path narrative. DetectCommunities is a connected-component MVP (not full Leiden).

Ingest:

  • File-tree: POST /api/context/index-tree or post-git_clone (EXTRACTED dir/file + contains)
  • Symbols: POST /api/context/index-symbols — Go via go/parser, JS/TS/Python via regex; SymbolIndexer interface ready for tree-sitter

RecordHoopContext/LookupHoopContext/HoopContextDigest and durable multi-wave "thread" facts still exist in contextgraph (hoop_context.go, thread_facts.go) but have no caller since the hoop/swarm stage runner that used to drive them was removed — dead library code, not a live feature.

Storage

  • Hot — internal/contextgraph.Store keyed by turn_family / request_uuid / connect_session
  • Warm events — JSONL under ~/.glider/context/events-YYYY-MM-DD.jsonl
  • Entities — ~/.glider/context/entities.jsonl
  • Episodes — compact outcomes for local prompts (contextkit)

What locals receive

Not the full TipTap mega-dump. Bounded pack: latest user turn + up to N compressed episodes (transform.local_context). Dashboard Overview paints episode chips from GET /api/context/episodes.
