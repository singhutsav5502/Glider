Pipeline step-by-step (tech per stage)

  1. Alias orchestrator.ApplyModelAlias · ModelAliases map · Metadata.OriginalModel
  2. Tokenize transform.Tokenizer.EstimateRequestTokens → Metadata.EstimatedTokens
  3. Route router.Engine.Route · ResolveBackendName · EventRouteDecided Priority: explicit → (MITM sticky outside engine) → tool_followup → classifier → Starlark → ceiling → default. See Routing.
  4. Origin gate (MITM only) CompleteOptions.OriginPassthrough · ErrOriginPassthrough Non-local → metrics origin_passthrough; interceptor tunnels to Cursor.
  5. Local context bind InjectEpisodeContext · BoundLocalContext (latest_turn policy) Only when Target=local. Sticky origin never reaches here.
  6. Transform (opt-in) Transformer.Apply · transform.enabled default false
  7. Execute Executor.Execute · Registry backend · VRAM warm · fallback / breaker
  8. Metrics + graph wrap goroutine drain chunks · LOCAL/CLOUD · EventFulfilledLocal · episodes

Fulfill hub step-by-step

  1. BidiAppend arrives cursorrpc.ExtractBidiCompletionRequest · TipTap latest turn
  2. Pre-DecideLocal belts explicit /cloud|/local · ShouldStickyCloudOrigin · wrap-up · InheritTurnFollowOn StickyCloud deny-local except allowlisted fresh TipTap user. See sticky state machine.
  3. DecideLocal (route only) PipelineCompleter.DecideLocal · no backend execute yet
  4. Arm hub ArmLocal(offer) or ArmOrigin · OpenTurnFamily · pending or signal waiter
  5. RunSSE Wait Wait(reqID, 800ms) · root only for text local · child → origin / would_local
  6. Fulfill or origin CompleteLocal + RunSSE encode · or dial api*.cursor.sh
